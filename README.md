# SQ-XGP 学术主页

这是一个适合 GitHub Pages 的静态站点。直接用浏览器打开 `index.html` 即可预览。

## 更新内容

- 在 `index.html` 中填写姓名、单位、个人简介和研究方向。
- 在 Publications 区添加论文题目、作者、会议或期刊、年份以及公开的论文或代码链接。
- 在 Contact 区添加你愿意公开的邮箱、Google Scholar 或 CV 链接。
- 个人资料补齐后，同步更新页面的 `title` 和 `description`。

## 发布到 GitHub Pages

1. 在 `sq-xgp` 账号下使用 `sq-xgp.github.io` 仓库。
2. 将本目录中的 `index.html`、`style.css` 和 `.nojekyll` 放到仓库根目录并提交。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。选择包含上述文件的分支以及 **/(root)**，然后保存。
4. 部署完成后访问 [sq-xgp.github.io](https://sq-xgp.github.io/)。

[GitHub Pages 官方快速入门](https://docs.github.com/en/pages/quickstart)
